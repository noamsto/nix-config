# Personal Profile Overlay

Loaded on personal machines (`osConfig.profile == "personal"`: g6, mbp-m4-pro).
Nix symlinks this file to `~/.claude/CLAUDE.profile.md`, which `CLAUDE.global.md`
imports.

Put **machine-bound** guidance here only. Repo-keyed workflow rules (Linear vs
GitHub issues, branch naming) live in `CLAUDE.global.md` — they're decided by
the repo's org, not by which machine you're on.
